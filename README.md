# Jimi Store — نسخة GitHub Pages (بدون PHP)

موقع ثابت (HTML + CSS + JavaScript). الطلب يتم برسالة واتساب جاهزة.

## النشر على GitHub Pages
1. أنشئ مستودع جديد (Repository) على github.com، واسمه مثلا `jimi-store`.
2. ارفع كل محتويات هذا المجلد (ليس الملف المضغوط نفسه) إلى المستودع: Add file ← Upload files.
3. من Settings ← Pages: اختر Branch = `main` والمجلد `/ (root)` ثم Save.
4. بعد دقيقة أو اثنتين يظهر الرابط: `https://اسم-حسابك.github.io/jimi-store/`

## تعديل المنتجات والأسعار
كل شيء في ملف واحد: `js/data.js`
- **السعر**: غيّر رقم `price`.
- **إخفاء منتج**: غيّر `active: true` إلى `active: false`.
- **منتج جديد**: ارفع الصورة إلى مجلد `images`، ثم انسخ سطر منتج وغيّر الكود والاسم والصورة.
- **رقم الواتساب**: السطر `whatsapp` (بالصيغة الدولية بدون +، مثال 249116583108).

يمكن التعديل من الموبايل مباشرة: افتح الملف في GitHub واضغط أيقونة القلم، ثم Commit changes.

## ملاحظات
- لا توجد لوحة أدمن ولا إحصائيات (لأن هذا يحتاج سيرفر).
- الروابط كلها نسبية، فالموقع يشتغل داخل مجلد المستودع بدون مشاكل.
